Basic Gaussians

C++ · raylib · WebAssembly Project 16

I've been working towards creating a Gaussians splat renderer. But first I wanted to create a basic 2D application for learning. It's actually remarkably simple. A gaussian, by definition is e^(-x^2). Translating into 2D we just get one equation per coordinate. It's controlalbe but shifting and multiplying be constants, eg 2e^(-(x + 5)^2). Or the classic normal distrubition. In code this translates to a very simple

struct Gaussian2D { glm::vec2 mu; glm::mat2 sigma; glm::vec4 color; };

The fancy statitical variable names can be renamed to, mu = position, sigma = rotationScale. The full mathematical formula is ** Show math formula ** And translated into code exp(-0.5 (p - mu)^T sigma^-1 (p - mu)) The -0.5f comes from ** add explincation **

glm::vec2 p = glm::vec2( x, y ); glm::vec2 diff = p - g.mu; float res = glm::exp( -0.5f * glm::dot( diff, sigmaInv * diff ) ); AddPixel( image, x, y, g.color * res );

That's it, suprising very simple. The difficulty comes in making these perforamnce and training these gaussians in the first place. A topic for another day.


Live demo

Click empty space to drop a splat, click one to select it, drag to move. The sliders retune whatever is selected, and whatever they are left on is what the next click places.

  • σx, σy the two axis lengths of the covariance, in pixels
  • rotation spins those axes, which is the off-diagonal term
  • weight peak amplitude, before anything overlaps
  • colour what the splat contributes where it lands
  • exposure tone mapping only, applied after the splats are summed
  • outlines the one-sigma ellipse of every splat, and the hit region for a click
