AI Arcade: Frozen Lake

C# · raylib · Tabular RL Project 22

As I've been learning Reinforcement Learning I've been implementing basic games to explore the algorithms. The first is the Frozen Lake, in which you start at the top left corner and reach the goal without falling into the holes. The goal has a reward of 1 and 0 elsewhere. The ice is slippery so there is a 2/3 chance to slide in a random direction.
